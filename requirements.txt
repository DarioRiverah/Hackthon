# `lap` (linear assignment problem solver): lo requiere el tracker
# ByteTrack de Ultralytics (pipeline/detect_and_track.py llama a
# model.track(...)) pero ultralytics NO lo declara como dependencia de
# instalación -- lo pide en tiempo de
# EJECUCIÓN vía su mecanismo de "AutoUpdate" (intenta un `pip install`
# automático la primera vez que hace falta). Confirmado dockerizando el
# proyecto (ver DOCKER.md / docs/architecture.md): sin esto, la primera
# corrida real del pipeline dentro del contenedor intenta descargar `lap`
# de internet a mitad de "Procesar video" -- justo lo que la imagen
# horneada de modelos (ver Dockerfile) existe para evitar. Se fija acá
# para que quede instalado en el build, nunca en tiempo de ejecución.
